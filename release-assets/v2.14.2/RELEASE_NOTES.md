# Sub2API CodexLink v2.14.2

## 悬浮状态改进

- 取消 Codex 顶部黑色整条悬窗。
- 按用户样例改为两枚白色轻量胶囊：右上角显示模式/余额，输入框上方显示上下文剩余比例。
- 悬窗支持点击穿透，不抢焦点、不遮挡 Codex 操作。
- 胶囊固定在 Codex 窗口的相对位置；拖动或缩放时由 Windows 位置事件立即带动，不再依赖定时轮询追赶。
- 根据 Codex 窗口和 DPI 自动计算位置，最小化时自动隐藏。
- 移动时不重复计算圆角，只在尺寸或内容变化时重绘，减少闪烁和跳动。
- rollout 扫描改为后台线程，避免读取大对话时卡住界面。
