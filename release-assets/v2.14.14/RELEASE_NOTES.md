# Sub2API CodexLink v2.14.14

## 会话模型诊断

- “运行状态”新增“配置模型”和“最近 rollout 模型”，明确区分默认 `config.toml` 与已有对话实际记录。
- 检测到模型不一致时只提示新建对话，不改写旧 rollout、SQLite 或历史对话。
- 国产直连和 Sub2API 切换完成后，如果旧会话模型不同，状态栏明确提示“请新建对话验证”。
- 最近 rollout 读取限制为首部与尾部窗口，避免诊断扫描大型对话时额外占满 C 盘或内存。

## 配置状态与会话模型说明修复

- 将国产直连状态明确标记为“配置生效”，不再暗示当前已打开的旧对话已经切换模型。
- 使用 DeepSeek 配置后，旧对话保留原有 `gpt-5.6-*` 会话模型；新建对话才使用新的默认配置。
- 使用本地 `config.toml` 作为配置目标证据，不把 Codex 官方模型菜单或固定自我介绍当作国产模型实际调用证据。

## 国产直连状态显示修复

- 国产直连生效时，顶部模式标记直接显示实际服务商和模型，例如 `DeepSeek · deepseek-v4-pro`。
- API 密钥区域同步显示实际生效的国产服务商和模型，不再误显示 Sub2API Key 或默认 `gpt-5.5`。
- 状态识别同时核对当前 `config.toml` 的自定义接口地址和模型；切回 Sub2API 或官方模式后不会继续误报 DeepSeek。
- 国产直连成功后，主界面模型框立即同步为实际写入模型。

## 国产模型预设

- 模型框改为可输入，写入 Codex 时使用当前文本，支持服务端新增模型或自定义模型 ID。
- 新增 DeepSeek、Kimi、Qwen、GLM、Baichuan、豆包等 OpenAI 兼容模型预设。
- Key 列表识别 DeepSeek、Moonshot/Kimi、DashScope/Qwen、智谱、百川、豆包、火山方舟、SiliconFlow、OpenRouter、OneAPI/NewAPI 和 custom 平台，不再只显示 OpenAI 平台 Key。
- 保持现有 Sub2API 直连机制：仍通过 `custom` provider、`/v1` 兼容地址和 `auth.json` 中的 `OPENAI_API_KEY` 生效，不保存任何新增密钥。

## 国产模型直连入口

- 主界面新增“国产直连”，不要求 Sub2API 管理台先存在对应上游分组。
- 支持直接填写 DeepSeek、Kimi、Qwen、GLM 或自定义 OpenAI-compatible 接口地址、API Key 和模型 ID。
- 切换前请求服务商 /v1/models 验证 Key 和接口；验证失败不会停止 Codex 或写入新配置。
- 成功后沿用现有事务回滚、对话索引同步和 Codex 自动重启流程。
- 直连 Key 的本地复用配置使用当前 Windows 用户 DPAPI 加密；真实 Key 不进入仓库、发布文件或日志。
- DeepSeek 默认模型调整为 `deepseek-v4-flash`，连接验证以服务端 `/v1/models` 实际返回列表为准；可手动选择 `deepseek-v4-pro` 等已返回模型。

## 关闭到系统托盘

- 点击原生标题栏 `X` 或按 Alt+F4 后，主窗口从任务栏消失并进入系统托盘，账号连接和余额刷新继续运行。
- 左键单击托盘图标或选择“打开主界面”恢复窗口；选择“退出程序”才会结束后台进程。
- 再次启动 CodexLink 时，可以唤回已经隐藏到托盘的单实例窗口。

## 主窗口原生拖动

- 主窗口改用 Windows 原生标题栏，不再通过 `ReleaseCapture` 和 `WM_NCLBUTTONDOWN` 模拟拖动。
- 移除自绘关闭按钮，使用系统最小化与关闭按钮；最小化按钮仍进入任务栏，关闭按钮和 Alt+F4 隐藏到系统托盘。
- 禁用最大化，保持固定工具窗口布局。

## 移除 Codex 悬浮胶囊

- 移除 Codex 标题栏余额悬窗和输入框上方上下文悬窗。
- 不再注册 Codex 窗口位置监听，也不再扫描 rollout 计算上下文比例。
- 余额、当前模式和真实生效 Key 继续在 CodexLink 主窗口及运行状态中显示。
- Codex 拖动、缩放和窗口合成不再受到 CodexLink 悬窗影响。

## 状态准确性

- 主界面新增真实生效 Key 标记，直接读取 `auth.json` 并只展示名称与末四位。
- 运行状态新增系统盘可用空间和实际 Key 末四位，方便在切换前确认环境。

## 稳定性保护

- 增加单实例保护，重复启动时恢复已有窗口，不再产生两套后台刷新和切换流程。
- 模式切换前检查最大 rollout 所需回滚空间，最低要求 1 GB。
- 完整对话备份前按实时数据量加 512 MB 预检，空间不足时在写入前停止。

## 自动更新

- 自动更新成功检查结果缓存 6 小时，降低 GitHub API 请求频率。
- GitHub 返回 403 限流时读取重置时间并退避；手动检查显示明确重试时间，后台检查不再刷错误。

## C 盘占用修复

- 修复账号切换为每个 rollout 复制完整文件、保留 6 轮后占满系统盘的问题。
- 回滚数据改为只保存被修改的首行元数据，成功或回滚后立即删除事务目录。
- 启动时自动清理超过 10 分钟的旧版 `.codex\backups\clp` 遗留快照，不删除真实对话、归档或任务回收站。
- 同一 Sub2API 模式内只切换 Key 时跳过历史对话同步。

## API Key 自动应用

- 用户在 Key 下拉框确认新选择后，自动验证 Key、停止 Codex、写入配置并重新启动。
- 写入后按所选 Key 精确比对 `auth.json`，不再只检查字段非空。
- 程序初始化和刷新列表造成的程序化选中不会误触发重启。

## 验证

- 新增首行快照大小、事务目录清理和旧快照空间回收测试。
- 保留账号切换回滚、对话恢复、任务删除与侧栏重建测试。
