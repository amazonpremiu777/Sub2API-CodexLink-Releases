# Sub2API CodexLink v2.14.0

## 新增

- 新增跟随 Codex 主窗口的状态栏，显示当前模式、Sub2API 余额和当前任务上下文剩余比例。
- 新增真正的任务删除，同时清理 rollout、SQLite、会话索引、全局分组和本地侧栏目录。
- 新增本机 7 天任务回收站，支持恢复和二次确认永久删除。

## 安全与一致性

- 删除前执行 WAL checkpoint 并建立操作快照；任一步失败会自动回滚。
- 删除同步清理父子任务边关系和动态工具记录，不会连带删除子任务。
- 回收站清单只保存任务 ID、标题、来源、原路径和删除时间，不包含账号或密钥。
- 不修改、不注入 Codex 安装文件；状态栏由 CodexLink 独立显示。

## 验证

- 保留 v2.13.5 的模式识别、provider 同步、侧栏重建和失败回滚回归测试。
- 新增上下文比例计算、任务删除、多层存储校验和回收站恢复测试。
