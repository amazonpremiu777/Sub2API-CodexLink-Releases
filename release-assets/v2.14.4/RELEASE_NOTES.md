# Sub2API CodexLink v2.14.4

## 窗口关闭行为

- 主窗口右上角 `X` 改为最小化，连接、余额刷新和跟随胶囊继续运行。
- Alt+F4 同样最小化；自动更新与异常终止仍能正常退出进程。

## 上下文准确性

- 改为依据 JSONL 内最新 `token_count` 事件时间选择任务，不再单纯依赖文件修改时间。
- 刷新间隔由 3 秒缩短为 1 秒，并缓存未变化的会话文件，减少重复读取。
- 多个任务在 2 秒内几乎同时更新时显示“上下文约剩”，避免把推测值标成精确结果。
- 继续使用 `last_token_usage` 计算当前上下文，不混入跨请求累计 Token。

## 验证

- 新增事件时间优先级、累计 Token 排除和近同时事件标记回归测试。
- 保留账号切换、对话恢复、任务删除/回收站与侧栏重建测试。
