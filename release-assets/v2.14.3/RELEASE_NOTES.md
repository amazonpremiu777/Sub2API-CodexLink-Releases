# Sub2API CodexLink v2.14.3

## 余额恢复

- 启动时立即显示当前服务地址对应的最后一次成功余额，并明确标记为“缓存”。
- 用户主动勾选“记住账号”后，下次启动使用 Windows DPAPI 凭据自动恢复 Sub2API 登录和实时余额。
- 需要 2FA 时不会绕过验证或保存临时验证码，改为提示用户手动登录。
- 实时余额读取成功后更新缓存；失败时保留最后一次余额，按 1、2、5 分钟退避重试。
- 余额解析兼容顶层及钱包对象中的常见字段，统一按不受系统小数格式影响的方式显示。

## 安全诊断

- 运行状态总览新增 `config.toml`、`auth.json`、Sub2API 地址和余额缓存时间检查。
- 新增“一键安全修复”：回滚中断切换、按需修复会话索引/数据库并修复快捷方式。
- 安全修复不会猜测账号模式，不会覆盖正常 `auth.json`，不会删除任务；会话修复失败仍按原事务规则回滚。

## 安全边界

- 不修改 Codex 的 `app.asar` 或官方安装文件。
- 不保存 Codex 官方账号令牌副本。
- 余额缓存不包含密码、Token 或 API Key。
- 保留关键模式配置的临时文件写入和原子替换机制。
